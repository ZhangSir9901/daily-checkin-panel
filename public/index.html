🌟 推荐方式：安装「签到面板 Cookie 助手」扩展，在目标网站登录状态下点一下扩展图标 → 「一键发送到签到面板」，自动打开面板并弹出确认框。能读取 HttpOnly Cookie，NodeSeek 这类站点也适用。支持 Chrome / Edge。

📋 取Cookie填入面板
在目标网站登录状态下点击书签，会自动打开面板并弹出 Cookie 填入确认框。HttpOnly 类型的 Cookie 浏览器不允许 JS 读取，这类站点仍需手动复制粘贴。

不用建书签的一次性代码，选好站点后复制：

用法：
1️⃣ 在手机浏览器打开目标网站（保持登录状态）
2️⃣ 把代码粘贴到地址栏
3️⃣ 光标移到最前面，手动输入 javascript:（浏览器粘贴时会自动吞掉它，必须手打，加上冒号）
4️⃣ 回车 → 自动跳回面板，弹出填入确认框，选账号保存即可
⚠️ 只能读到普通 Cookie，读不到 HttpOnly 类型的登录 Cookie（如 NodeSeek）。如果导入后网站不认登录信息，请改用 cURL / 请求头 / JSON / cookie.txt 方式
用法：
1️⃣ 在电脑浏览器打开目标网站（保持登录状态），按 F12 打开开发者工具
2️⃣ 切换到 Console（控制台）标签页，输入 document.cookie 回车
3️⃣ 把返回的那串 名称=值; 名称=值 复制，粘贴到上面
⚠️ 只能读到普通 Cookie，读不到 HttpOnly 类型的登录 Cookie（如 NodeSeek）。如果导入后网站不认登录信息，请改用 cURL / 请求头 / JSON / cookie.txt 方式
从 cURL 里自动提取 Cookie；如果还带了 User-Agent（如吾爱破解必填 UA），新建账号时会自动填入。
💡 浏览器 F12 → 网络 → 点任一请求 → 复制请求头：Cookie 那行下面就是 User-Agent，一起粘贴过来，吾爱等站点新建账号时 UA 会自动填入。

添加账号

取 token 步骤：① 在浏览器登录 akile.ai → ② 点下面按钮复制小书签代码，新建一个书签粘贴进去 → ③ 在 akile.ai 页面点该书签，token 会自动复制 → ④ 粘贴到下方输入框保存。
token 临近过期时面板会自动续期；续期失败会提示重新获取。
快捷录入：在电脑浏览器人工登录该网站并完成一次签到 → F12 网络面板找到签到请求 → 右键「复制为 cURL」→ 粘贴到下面 → 点「从 cURL 导入」（Cookie 会自动带入，无需手动复制）。
也可以输入网站首页地址，点「自动探测」让面板自动寻找候选签到接口，点候选结果即可填入。
