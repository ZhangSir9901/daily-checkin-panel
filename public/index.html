🧩 浏览器扩展 cookie插件2.2

检测中… ⬇️ 下载 cookie插件2.2

它干两件事：① 一键取 Cookie（能读到 HttpOnly，NodeSeek 这类站也行）； ② 做「本地网络中继」，让吾爱破解这些屏蔽机房 IP 的站点也能签到。

  1. 点右侧「⬇️ 下载 cookie插件2.2」，得到 zip，解压到任意文件夹
  2. 浏览器地址栏输入 chrome://extensions/（Edge 用 edge://extensions/），打开右上角「开发者模式」
  3. 点「加载已解压的扩展程序」，选中解压出来的文件夹（不是 zip 本身）
  4. 点扩展图标 → 填「API Key」（在「设置」页复制）→ 点「🔌 面板连接检查」

💡 从本面板下载的扩展已自动填好面板地址；以后改了域名，在扩展弹窗里同步改一下即可。

🔌 浏览器扩展

安装「cookie插件2.2」扩展后，它就是面板的本地网络中继：面板点「执行」时请求由扩展在您的浏览器里发出（用您的本机 IP 和登录态），因此能绕过 CF 网络的 IP 封禁与人机验证。扩展会自动挂长轮询接单，响应通常在 1 秒内。扩展需要下面的 API Key 才能连接面板。

中继状态：检测中… 扩展在线时，标记为「🌐 本地网络」的账号会经您的本机网络执行

⬇️ 下载 cookie插件2.2
1️⃣ 解压上面下载的 zip（得到一个文件夹）
2️⃣ 打开 chrome://extensions/（Edge 用 edge://extensions/）→ 打开右上角「开发者模式」
3️⃣ 点「加载已解压的扩展程序」→ 选中解压出来的那个文件夹
4️⃣ 点扩展图标，把下面生成的 API Key 填进去 → 点「🔌 面板连接检查」

把 Key 填到扩展弹窗的「API Key」输入框并保存，扩展就会开始工作。Key 泄露时点「生成」换一个新的。

添加账号

取 token 步骤：① 在浏览器登录 akile.ai → ② 点下面按钮复制小书签代码，新建一个书签粘贴进去 → ③ 在 akile.ai 页面点该书签，token 会自动复制 → ④ 粘贴到下方输入框保存。
token 临近过期时面板会自动续期；续期失败会提示重新获取。
快捷录入：在电脑浏览器人工登录该网站并完成一次签到 → F12 网络面板找到签到请求 → 右键「复制为 cURL」→ 粘贴到下面 → 点「从 cURL 导入」（Cookie 会自动带入，无需手动复制）。
也可以输入网站首页地址，点「自动探测」让面板自动寻找候选签到接口，点候选结果即可填入。
